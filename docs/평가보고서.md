## 4. 주요 문제 해결 기록

### P1 — 중첩 레포 구조 (Nested Repository)
- **현상:** 프로필 레포 안에 새 레포를 만들면 바깥 레포가 안쪽 폴더를 추적 시도
- **해결:** 바깥 `.gitignore`에 `2026-06-04/` 추가 → `git check-ignore` 검증
- **결과:** 두 레포 완전 독립, 서로 영향 없음

### P2 — 멀티계정 403 Push 오류
- **현상:** `gh auth switch` 후에도 `git push` 시 iggn-official 계정으로 밀어붙여 403
- **원인:** gh CLI 계정 ≠ Windows Credential Manager 캐시 (별개 시스템)
- **해결:** `git config --local credential.helper "!gh auth git-credential"`
- **결과:** 레포 단위로 자격증명 분리, 전역 설정 영향 없음

### P3 — 커서 패럴랙스 미작동
- **현상:** 히어로 이름에 `mousemove` 이벤트로 `transform` 적용해도 시각적 변화 없음
- **원인:** CSS `@keyframes rise`가 `animation-fill-mode: both`로 인해 `transform` 속성을 계속 점유
- **해결:** 이름 등장 애니메이션을 `transform`을 건드리지 않는 `fadein`(opacity only)으로 교체
- **결과:** JS transform 정상 작동, 패럴랙스 효과 강도 3배 향상
