## 1. 작업 환경 세팅

### 1-1. 독립 레포 구조 설계

강사 프롬프트는 "레포를 클론하고 개발 준비해줘"였지만, 더 깔끔한 방법을 선택했다.

- 기존 `restboy2606` 프로필 레포 **안에** 오늘 수업 폴더를 만들되,  
  **중첩 레포(nested repo) 문제**를 피하기 위해 아래 구조로 설계

```
restboy2606/              ← 기존 프로필 레포 (바깥)
├── .gitignore            ← "2026-06-04/" 추가 → 안쪽 폴더 무시
└── 2026-06-04/           ← 오늘 수업 폴더 = 독립 레포 (안쪽)
    └── .git/
```

**왜 중첩이 문제냐:** 바깥 레포가 안쪽 폴더를 추적하려다 git이 꼬인다.  
**해결:** `.gitignore`에 `2026-06-04/` 추가 → 두 레포가 완전히 독립.

```bash
git init -b main          # 안쪽 레포 초기화
# 바깥 .gitignore에 추가
git check-ignore -v 2026-06-04/   # 차단 확인
```

### 1-2. GitHub 멀티계정 이슈 해결

이 머신에 GitHub 계정이 두 개 등록되어 있었다(`iggn-official`, `restboy2606`).  
`gh auth switch`로 활성 계정을 바꿔도, **git push는 Windows 자격증명 관리자(Credential Manager)** 캐시를 따로 쓰기 때문에 `iggn-official`로 밀어붙여 **403 에러** 발생.

```
remote: Permission to restboy2606/2026-06-04.git denied to iggn-official.
```

**해결:** 레포 단위로 git credential을 gh CLI로 연결

```bash
git config --local credential.helper ""
git config --local --add credential.helper "!gh auth git-credential"
```

> 💡 **교훈:** `gh auth switch` ≠ git push 자격증명. 두 시스템이 따로 논다.

## 2. GitHub Actions 배포 파이프라인 구성

강사가 Settings → Pages → Source를 **GitHub Actions**로 바꾸라 했다.  
왜인지 미리 파악: 정적 HTML/Jekyll이 아닌 **빌드 단계가 있는 프로젝트(React 등)를 배포**하려면 Actions가 필요하기 때문.

`.github/workflows/deploy.yml` 작성 — push 감지 → Pages 자동 배포:

```yaml
on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: { path: '.' }
      - uses: actions/deploy-pages@v4
```

**push → Actions 자동 실행 → Pages 배포** 파이프라인 완성.  
배포 URL 라이브 확인: HTTP 200, 약 12초 소요.

## 4. JavaScript 인터랙션

**외부 라이브러리 0개, 바닐라 JS 순수 구현.**  
`prefers-reduced-motion` 미디어쿼리로 접근성(모션 민감 사용자) 대응.

| 효과 | 구현 방법 | 발동 |
|------|-----------|------|
| 텍스트 스크램블 디코드 | `setInterval` 45ms + 글자별 reveal 타이밍 | 로드 시 자동 + 마우스 hover |
| 커서 패럴랙스 | `mousemove` 좌표 정규화 → `rotateX/Y + translate` | 히어로 영역 마우스 이동 |
| 이모지 폭죽 | `Web Animations API` + 물리 벡터 계산 | 이름 클릭 |
| 배럴롤 | CSS `@keyframes rotate(360deg)` | 빨간 점 클릭 |
| AI 슬롭 모드 토글 | `data-*` 속성 + Comic Sans + 보라 그라데이션 소환 | 푸터 이스터에그 클릭 |

> ⚠️ **버그 & 해결:** 커서 패럴랙스가 처음에 안 됐던 이유 — CSS `@keyframes rise`가 `transform`을 점유(fill-mode: forwards)해서 JS transform이 덮어써지지 않았다.  
> **해결:** 이름 등장 애니메이션을 `transform`을 건드리지 않는 `fadein`(opacity만)으로 교체.

- 이벤트색은 항상 **밝은색 배경 + 어두운 글자** OR **어두운 배경 위** 에서만 사용
- 다크모드에서 강조색을 어두운 원색 → 밝은 파스텔로 자동 전환
